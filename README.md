# 分層手勢重播

免 Root 的 Android 分層滑動錄製與重播工具。

## v1.1.0 懸浮控制器

- `≡`：拖曳控制器。
- `錄`：在目前畫面上開啟透明錄製層。
- `播`：播放一次所有已儲存軌跡。
- `循`：循環播放。
- `停`：停止播放。
- `×`：關閉；可回主程式重新顯示。

懸浮控制器能顯示在其他 App 上方，不需要另外授予懸浮視窗權限。
錄製時透明層會接收觸控，所以底下 App 不會同時收到該次滑動；
播放時則會將軌跡送到目前前景 App。

## 功能

- 每次錄製一條滑動軌跡
- 多條軌跡在同一個 `GestureDescription` 中疊加播放
- 每條軌跡的起點與長度都可用 0.1 秒為單位微調
- 軌跡可上移、下移調整播放順序
- 可保存多個命名版本，並套用、覆蓋更新、改名或刪除
- 可將目前軌跡與全部保存版本匯出成 JSON 備份檔
- 新安裝內建並直接套用「原地速量留」手勢（9 條軌跡、總時間 4.4 秒）
- 更新既有安裝時不覆蓋目前軌跡或同名的「原地速量留」保存版本
- 軌跡記錄來源螢幕尺寸，換手機播放時自動縮放座標
- 舊版軌跡以 1080 × 2340 為來源尺寸相容換算
- 停止、關閉懸浮控制器或直接退出 App 都會取消循環及當輪手勢
- 單次或循環播放
- 本機保存，不使用網路、不含廣告
- 無障礙服務不讀取畫面內容

## Android 限制

- 錄製透明層會攔截該次操作，底下 App 不會同時收到錄製手勢。
- 播放期間的手動觸控可能取消合成手勢。
- 部分遊戲與安全 App 可能拒絕或禁止自動操作。
- 目前以路徑形狀及總持續時間重播，不逐點重現每一段速度。

## 全自動辨識實驗版

實驗版使用獨立套件
`com.example.gesturereplayzh.autoexperimental`，可與穩定版同時安裝。
移除實驗版不會刪除或取代穩定版資料。

- 僅在使用者明確勾選允許並按下懸浮控制器的「自」後擷取畫面。
- 地圖選點只使用中央有效區，排除頂部、右側功能鍵與底部選單。
- 掃描區改以角色位置（畫面寬 50%、高 63%）為圓心；寶可夢使用內圈，
  補給站使用稍大的外圈，並排除因透視而過小的遠方補給站。
- 使用三張連續畫面先校正地圖位移；畫面擷取至少相隔 0.35 秒，避免
  Android 因截圖要求過密而拒絕後進入較慢的失敗重試。只有前後兩段
  都存在的差異才形成候選，避免單張道路邊界殘影。
- 不再膨脹差異遮罩，直接把不相連的像素群分割成獨立個體，再依尺寸、
  細長度、填充率、顏色、局部邊緣與陰影分類。
- 道路、水域、草地及建築底圖會依大面積連續性、平滑程度與低局部邊緣排除。
- 黃綠道路邊界會依黃綠比例、細長度與低陰影排除；大型紅白／青藍結構
  會歸類為道館並跳過。寶可夢優先，沒有寶可夢時才選藍色補給站。
- 點擊位置使用物件動態區域的加權中心，不再使用掃描格中心。
- 紫色補給站、大型道館及極巨化建築會被排除。
- 點入後只判斷底部控制：大型寶可夢球、圓形 X、地圖小精靈球或沒有按鈕。
- 沒有底部按鈕時依火箭隊流程點擊兩次，預設間隔 0.6 秒，再按 X。
- 自動捕捉來源可明確選擇「目前套用手勢」或任一保存版本；主畫面會顯示
  實際來源、軌跡數與總長度，播放前也會顯示實際軌跡數，避免誤用內建版本。
- 每次自動點擊目標後約 0.65 秒開始第一次畫面判斷；若仍在載入，
  後續約每 0.25 秒重新檢查。大型寶可夢球只需一次明確判定即可播放手勢；
  未知畫面最多連續四次後才進入火箭隊流程。
- 地圖狀態確認圖會直接作為第一張分析圖，不再每輪拍攝四張；預設掃描
  間隔由 0.8 秒調成 0.3 秒，舊版未修改的預設值會自動遷移。
- 自動捕捉播放前會清除控制器內待執行的掃描回呼與殘留影格；預設穩定
  等待由 0.3 秒調成 0.7 秒。若手勢被取消，等待 0.9 秒並重新確認仍在
  捕捉畫面後才重試，最多重試兩次。
- 若遊戲把「我不是駕駛／我是乘客」按鈕公開給 Android 無障礙服務，
  實驗版會先執行按鈕動作；若節點不可點，則改點文字節點的畫面中心，
  確認完成後等待 2 秒並重新判斷目前畫面。
- 所有自動畫面擷取都會優先檢查移動速度警告：中央大型白色警告框及
  綠色漸層「我不是駕駛」按鈕同時成立時，點擊畫面寬 50%、高 66%；
  因此即使遊戲沒有公開無障礙文字節點也可處理。
- 寶可夢候選改採保守規則：動態強度、尺寸、局部邊緣、形狀緊密度必須
  同時達標，人物形狀、平坦地貌、大型建築、紫色補給站與低可信候選不點擊。
- 操作描述、時間、點擊次數及點擊位置可以修改；畫面判斷條件不可修改。
- 全自動設定內容區限制高度並可捲動，保存、取消及恢復預設按鈕固定保留
  在對話框底部，不會再被較小螢幕擠出畫面。
- 自動模式啟動後，懸浮控制列會縮成右上角的「自停」按鈕。
- 每輪掃描前先判斷目前畫面：若啟動時已在捕捉畫面就播放目前手勢；
  若已在補給站、道館或其他含下方 X 的畫面就先退出；只有確認是地圖
  主畫面才開始三幀目標掃描。捕捉或退出後也會再次確認狀態。

開始前需將遊戲地圖保持在最大視野、最高角度，並隱藏第三方功能按鈕。
這是未經手機實機測試的實驗功能，第一次使用應採用非重要帳號並全程觀察。
遊戲營運商可能把畫面辨識及自動操作視為違規自動化。
