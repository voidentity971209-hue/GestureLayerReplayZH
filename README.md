# 分層手勢重播

免 Root 的 Android 分層滑動錄製與重播工具。

## v1.1.0 懸浮控制器

- `≡`：拖曳控制器。
- `錄`：在目前畫面上開啟透明錄製層。
- `播`：播放一次所有已儲存軌跡。
- `循`：循環播放。
- `停`：停止播放。
- `×`：關閉；可回主程式重新顯示。

懸浮控制器能顯示在其他 App 上方，不需要另外授予懸浮視窗權限。
錄製時透明層會接收觸控，所以底下 App 不會同時收到該次滑動；
播放時則會將軌跡送到目前前景 App。

## 功能

- 每次錄製一條滑動軌跡
- 多條軌跡在同一個 `GestureDescription` 中疊加播放
- 每條軌跡的起點與長度都可用 0.1 秒為單位微調
- 軌跡可上移、下移調整播放順序
- 可保存多個命名版本，並套用、覆蓋更新、改名或刪除
- 可將目前軌跡與全部保存版本匯出成 JSON 備份檔
- 新安裝內建並直接套用「原地速量留」手勢（9 條軌跡、總時間 4.4 秒）
- 更新既有安裝時不覆蓋目前軌跡或同名的「原地速量留」保存版本
- 軌跡記錄來源螢幕尺寸，換手機播放時自動縮放座標
- 舊版軌跡以 1080 × 2340 為來源尺寸相容換算
- 停止、關閉懸浮控制器或直接退出 App 都會取消循環及當輪手勢
- 單次或循環播放
- 本機保存，不使用網路、不含廣告
- 無障礙服務不讀取畫面內容

## Android 限制

- 錄製透明層會攔截該次操作，底下 App 不會同時收到錄製手勢。
- 播放期間的手動觸控可能取消合成手勢。
- 部分遊戲與安全 App 可能拒絕或禁止自動操作。
- 目前以路徑形狀及總持續時間重播，不逐點重現每一段速度。

## 全自動辨識實驗版

實驗版使用獨立套件
`com.example.gesturereplayzh.autoexperimental`，可與穩定版同時安裝。
移除實驗版不會刪除或取代穩定版資料。

- 僅在使用者明確勾選允許並按下懸浮控制器的「自」後擷取畫面。
- 地圖選點只使用中央有效區，排除頂部、右側功能鍵與底部選單。
- 使用三張連續畫面先校正地圖位移，再以殘餘動畫、局部邊緣、
  尺寸與緊密程度找尋候選目標。
- 道路、水域、草地及建築底圖會依大面積連續性、平滑程度與低局部邊緣排除。
- 點擊位置使用物件動態區域的加權中心，不再使用掃描格中心。
- 紫色補給站、大型道館及極巨化建築會被排除。
- 點入後只判斷底部控制：大型寶可夢球、圓形 X、地圖小精靈球或沒有按鈕。
- 沒有底部按鈕時依火箭隊流程點擊兩次，預設間隔 0.6 秒，再按 X。
- 自動捕捉直接播放主畫面「目前套用的手勢」；可在主畫面調整名稱、
  描述、起點、長度、順序，或套用任一已保存版本。
- 每次自動點擊目標後固定等待 2 秒才進行第一次畫面判斷；若畫面仍在載入，
  後續約每 0.4 秒重新檢查，連續兩次確認大型寶可夢球才播放目前手勢；
  截圖間隔符合 Android 11 限制，失敗時會重試同一判斷步驟。
- 捕捉手勢若被 Android 取消，會在 0.3 秒後重試一次。
- 若遊戲把「我不是駕駛／我是乘客」按鈕公開給 Android 無障礙服務，
  實驗版會優先按下並在 2 秒後重新掃描；若遊戲只把提示畫在影像中，
  則需要另提供該提示截圖才能加入影像辨識。
- 寶可夢候選改採保守規則：動態強度、尺寸、局部邊緣、形狀緊密度必須
  同時達標，人物形狀、平坦地貌、大型建築、紫色補給站與低可信候選不點擊。
- 操作描述、時間、點擊次數及點擊位置可以修改；畫面判斷條件不可修改。
- 自動模式啟動後，懸浮控制列會縮成右上角的「自停」按鈕。

開始前需將遊戲地圖保持在最大視野、最高角度，並隱藏第三方功能按鈕。
這是未經手機實機測試的實驗功能，第一次使用應採用非重要帳號並全程觀察。
遊戲營運商可能把畫面辨識及自動操作視為違規自動化。
