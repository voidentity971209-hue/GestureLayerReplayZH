# 刷機（GestureLayerReplayZH）

免費、免 Root 的 Android 手勢錄製與重播工具。實驗版另有可選的畫面自動流程。

## 0.17.6 嚴格框選區版

- 不再使用 TFLite、訓練資料或舊地圖物件模型。
- 每次按下懸浮「自」後，直接拖曳框住完整 Pokémon 條列；不需要命名。
- 自動流程啟動後，懸浮列向右縮起，只留下可立即暫停的「停」。
- 可自由框選較小的辨識區。
- 地圖候選只分析框中央 60% 的內容，點擊位置固定在框的水平中央。
- 所有地圖候選點擊都必須位於框內安全邊界；超出即拒絕。
- 啟動時依序框選「條列辨識區」與「地板點擊區」。
- 條列空白時，每輪最多點一次所選地板區中央；不再猜測或點擊其他地板。
- 候選點擊後仍是地圖時，封鎖該位置 10 秒。
- 保留條列候選連續點擊兩下及可調整的連點間隔。
- 放開手指後立即鎖定本次範圍並開始，只分析框內內容。
- 自動排除框內最上方控制標誌與最下方雷達區域。
- 自動運行時控制器縮到右側，只留下「停」，可立即暫停。
- 找到框內圖示列後逐項點擊；每次動作後重新截圖，但框選範圍維持不變。
- 沒有條列候選時，只點使用者另外框選的地板區中央；每輪最多一次。
- 捕捉畫面可自行勾選相機區、名稱／CP、左右功能欄與中央大型球等判定項目。
- 確認捕捉後只播放主畫面的「目前手勢」，保留既有手勢、保存版本與 JSON 備份。
- 未知畫面不觸控；補給站、道館等只有偵測到真正下方 X 才退出。
- 條列連點次數、連點間隔、點後辨識等待、捕捉前後等待、地板等待、火箭隊、退出與封鎖參數都能在 App 內調整。

## 安全限制

畫面自動操作可能誤判，也可能違反目標服務的使用規則。請勿用於重要帳號、付款或密碼畫面。
