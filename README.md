# 刷機（GestureLayerReplayZH）

免費、免 Root 的 Android 手勢錄製與重播工具。實驗版另有可選的畫面自動流程。

## 0.17.2 固定條列與捕捉修正版

- 不再使用 TFLite、訓練資料或舊地圖物件模型。
- 在整個畫面搜尋 PGSharp 類型的垂直 Pokémon 條列，不假設它位於固定位置。
- 白色「＝」是固定長條的定位標誌，不是按鈕；程式永遠不會點擊它。
- 排除長條最上方「＝」和最下方雷達，直接分析其間的 Pokémon 圖示列。
- 即使固定地圖介面被外掛面板遮住，只要辨識到條列仍會繼續流程。
- 找到條列後辨識其中圖示列，逐項點擊；每次動作後重新截圖，不沿用舊座標。
- 沒有條列候選時，只嘗試玩家附近的短距離安全地板點。
- 捕捉畫面不使用逃跑／跑步圖示；由相機區、名稱／CP 區、左右功能欄及中央大型球共同確認，並優先於地圖判定。
- 確認捕捉後只播放主畫面的「目前手勢」，保留既有手勢、保存版本與 JSON 備份。
- 未知畫面不觸控；補給站、道館等只有偵測到真正下方 X 才退出。
- 條列連點次數、連點間隔、點後辨識等待、捕捉前後等待、地板等待、火箭隊、退出與封鎖參數都能在 App 內調整。

## 安全限制

畫面自動操作可能誤判，也可能違反目標服務的使用規則。請勿用於重要帳號、付款或密碼畫面。
